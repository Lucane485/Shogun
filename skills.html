HTML

Das Konstrukt einer jeden Internetseite. HTML ist der Inhalt der Seite und liefert jegliche Elemente. Dafür ist HTML statisch und Unflexibel.

WORD

Das Programm zum Texte schreiben. Lebensläufe verfassen und so weiter. Word ist ein kostenpflichtiges Programm von Microsoft, womit man alles mögliche Schreiben kann, was man will und wie man will. Dazu kann man verschiedenste Formen oder sogar Bilder und Videos einfügen und sie entsprechend anpassen.

CSS

Die Anforderungen von HTML. CSS entscheidet, wie eine Seite Aussehen soll. HTML-Baut, CSS-Designt. CSS kann aber auch interaktiv sein und einfache Animationen abspielen, ist aber dafür bei der Interaktivität eingeschränkt.

POWERPOINT

Das Vortrag Programm. Gerne mal wird gesagt, dass man eine PowerPoint machen soll, aber was ist das. PowerPoint ist ein Programm von Microsoft sowie Word und Excel und dient dazu meist Vorträge vorzubereiten, aber man kann auch z.B. ein Mockup machen, was wichtig in der Programmier-Branche ist.

JAVASCRIPT

Das Leben in der Seite. Was bringt es eine Vollkommene Seite ohne Leben zu Kreieren. JavaScript ist schwieriger als HTML oder CSS, kann aber dafür jegliche Interaktionen durchführen, von Textveränderungen bis zum Wortwörtlichem Leben auf der Seite.

EXCLE

Excel. Tabellen, Rechnen, Vergleichen, den PC für einen Arbeiten lassen. Das Programm von Microsoft, Excel. Excel wird oft in Büro Jobs verwendet, um z.B. Aufgaben auszurechnen und Aufträge einfacher auszuführen. Aber man kann auch andere Sachen mit Excel machen, besonders als Schüler ist Excel sehr gut geeignet, Inhaltsverzeichnisse zu machen oder derartiges.
